# 2026格式核对与剩余材料

2026-09-11直接查阅[论文格式规范（2026修订）](https://www.mcm.edu.cn/html_cn/node/4cd596519c9eb9fbd866398f6df0caa3.html)与[AI工具使用规定（2026试行）](https://www.mcm.edu.cn/html_cn/node/fef94648f2836ab6cc81586f4c38512b.html)。当前交付是英文Markdown审阅稿和工作簿审阅副本，未声称通过正式PDF验收。

| 要求 | 当前状态/下一步 |
|---|---|
| A4、四边至少2.5cm、摘要含标题关键词原则上一页 | Markdown不能证明页边距/分页；正式排版时检查 |
| 正文无目录、不超过30页；附录页数不限 | 指定表已入各问题；最终PDF需实测页数，不能按Markdown行数推算 |
| 摘要页开始页脚居中连续编号；电子版不放承诺书和编号页 | 当前尚无最终电子论文，后续按此排版 |
| 附录含支撑文件清单、全部完整可运行程序代码 | 当前仓库保留完整程序；正式论文附录仍需排入，不能只写Git链接 |
| 正文、附录、支撑文件无身份、学校、赛区信息 | 内部报告含可追溯本机路径及Git信息，不可整目录直接提交；正式副本须清理元数据和身份路径 |
| 论文单个PDF或Word≤20MB；支撑材料单个ZIP/RAR≤20MB | 旧几十MB的分卷属于内部归档，不能原样充当支撑材料；正式包应只含必要代码/配置/输出/说明，原题数据按规则不重复打包 |
| AI声明在参考文献前、另附真实使用详情PDF | 已整理`papers/revision_v1/AI工具使用详情_工作稿.md`；缺人工核验及全体成员工具记录，不能编造PDF最终声明 |

新英文稿的公式和表号已统一。三线表的线宽、跨页重复表头、图号连续、英文图字号及正文引用，须以最终Word/PDF逐页检查结果为准。没有逐页检查的文件不标“正式提交”。此文件处理朋友清单的版式项，不把这些事项伪装成需重跑的实验问题。
