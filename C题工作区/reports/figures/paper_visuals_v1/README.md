# Paper Visuals v1

This package contains English-only, 300 dpi PNG and scalable SVG figures for the current English manuscript. Each figure is built from a copied input file or, for the framework diagram, from the declared workflow in the manuscript. No source data, time key, solver output, or frozen deliverable is overwritten.

| Paper figure | Asset directory | Evidence represented |
|---|---|---|
| Figure 1 | `overall_framework` | Declared information flow, shared physical constraints, and audit boundary. |
| Figure 2 | `q1_dispatch` | The 144-interval deterministic dispatch, storage state, and fixed tariff. |
| Figure 3 | `q2_policy` | D112, X_strong, January-selected, and seasonal policy costs, plus monthly D112-X_strong differences. |
| Figure 4 | `q2_uncertainty` | D112-X_strong block-resampling intervals and day-level win/loss counts. |
| Figure 5 | `q3_updates` | Raw-PV update policies versus the midnight-only control. |
| Figure 6 | `q4_value` | Fixed-price planning input versus causal OLS price input under actual-price settlement. |
| Reserve figure | `q4_prices` | Four prescribed dates of causal price forecasts and realized prices. |

Figures 3 and 4 are generated by `scripts/paper_visuals_v1/render.py`; their copied daily ledgers, block-bootstrap output, and win/loss output are retained in the respective `data/` directories. Figures 2, 5, 6, and the reserve figure re-run the already reviewed project ModelViz-derived renderers against copied inputs; their renderer copies are retained in each `workspace/` directory. The `plot_facts.json` files record the numerical quantities shown in the custom figures or in the original renderer.

The project drawing instruction names `/Users/justingao/.codex/skills/modelviz-skill/SKILL.md`, but that skill path is unavailable on this host. The package therefore uses the project's existing reviewed ModelViz-derived plotting scripts and their English scientific style; it does not claim that a new ModelViz service run or template-selection audit occurred. Visual inspection was performed after each render. The output set can be recreated with the existing plotting environment and the copied source files.

Figure 4 must be read as an observed-path diagnostic only: both total-cost resampling intervals include zero, and it is not evidence of global optimality, statistical significance, or future-year performance. Figure 3 is similarly an historical replay comparison. The `q4_prices` chart is useful supporting evidence but is not inserted into the main manuscript to avoid overloading the Problem 4 results section.
