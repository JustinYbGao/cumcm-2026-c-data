# v4 数学与代码独立审读

审读对象：`kernel.c`、`kernel.py`、`policy.py`、`run_experiments.py`、`causality_checks.py` 和 `analyze_results.py`。独立验证程序不导入这些模块，仅用标准库、NumPy 和 pandas 重建预测、执行、情景目标及分析。

## 解析导数

令 a=∂S′/∂S、b=∂S′/∂q、u=∂e/∂S、v=∂e/∂q，充放效率 η=.9。在非折点，各活动分支的导数为：

| 分支 | a | b | u | v |
|---|---:|---:|---:|---:|
| 盈余小于充电功率和空间限制 | 1 | η | 0 | 0 |
| 充电受功率限制 | 1 | 0 | 0 | 0 |
| 充电受容量上限限制 | 0 | 0 | 0 | 0 |
| 缺口小于放电功率和可用能量 | 1 | 1/η | 0 | 0 |
| 放电受功率限制 | 1 | 0 | 0 | −1 |
| 放电受可用能量限制 | 0 | 0 | −η | −1 |

给定终端伴随量 λ_T=−μ，单情景逆推为 λ_t=κp_tu_t+λ_(t+1)a_t；采购梯度为 p_t+mean(κp_tv_t+λ_(t+1)b_t)。C99 内核实现与此一致，实际紧急费用输出仍为 5p；κ 只影响规划目标。缩放变量 y=q/1000、目标 f=J/10000 后，应向优化器传入 .1∂J/∂q，`policy.py` 正确实现了该因子。

独立前向 144 维灵敏度与 C99 反向结果在 1e-9 内一致。全部 144 个坐标的中心有限差分最大误差为 3.60×10⁻⁷，扰动步长 1e-4 kWh，样例距活动分支折点的最小间隔 1.0713 kWh。证据见 `independent_gradient.json`。

在 min/max 的相等点，普通梯度通常不存在；代码选取一个活动分支导数用于启发式搜索。这并不将非光滑问题转化为光滑问题，L-BFGS-B 的 success、投影梯度或相对目标停止条件不能作为全局或严格局部最优性证明。

## 采购、物理与结算

每天的两个起点均使用该策略自己的实际日初库存；全部情景共享同一 144 维采购向量。所有场景都按本段净负荷和已有库存严格贪心执行，不选择具有前视权限的自由补救动作。生产代码把名义回放写到 `forecast_` 列，实际紧急采购只进入 `emergency_kwh` 及其 5p 现金成本，未将名义缺口充进电池。

独立程序验证全部候选的情景费用、末态、经验目标、NaN 尾部、场景来源、风险初始化器、择优规则、优化器初点/最小已评估点/返回点及标量轨迹。原一月缺少初始化器完整轨迹的问题已通过追加 `initializer_certificate.npz` 解决：保留原件，重新计算须先逐位核对全部 q 与 score，独立程序再核验新增轨迹的守恒、互斥、功率、SOC、弃光上限与固定 1200 kWh 末态。

已验证最终实际调度不依赖初始化器固定末态约束；它只提供一个候选初值。实际逐日库存连续、普通采购冻结、未用合同电量照付费，实际费用与库存估值分开。

## 终止记录与敏感性

保留未收敛记录合理：达到迭代上限的点仍可物理可行且较初点得分低。是否保留候选由重新计算的目标决定，不能把非 success 改写为成功。初轮 180 迭代和后续 1200 迭代是两组独立保留的历史实验；后者由已观察结果触发，不能追溯称为全部预先登记。

原一月未记录单次优化耗时，报告须明确这一限制。年度及随后新增运行已记录并独立核对优化器单次耗时的累计值、最大值与 MILP 的累计值、最大值。耗时仅代表这次机器运行。
