# 方法统一与保留的分支差异

| 项目 | 旧Q2 B0 / 旧Q3与Q4 | Q2 D112与新统一分支 |
|---|---|---|
| 采购目标 | 点预测MILP购电费；日内为A合同费，忽略历史误差下实际紧急风险 | 在非负采购向量上最小化规划合同费+历史场景严格贪心紧急费−固定μ库存净增代理 |
| 场景执行 | 旧MILP名义充放电最优调度，实际另贪心 | 所有候选在所有历史场景中逐段贪心，不能自由选择补救调度；真实执行仍贪心 |
| 信息 | Q2午夜B0；Q3发布PV；Q4另预测价 | 相同权限保留。新场景残差必须与当前使用的PV源发布阶段匹配，负荷保持午夜B0 |
| 初态 | 旧Q3已有实际SOC反馈、实际跨日连续 | 每次初始化器和场景都用本策略当前实际E，不借别策略计划或日初SOC |
| 终态 | 旧Q3/Q4名义末态等于日初，D112初始化器1200 | 最终q不强制名义零缺口及日末等式；初始化器末态1200只给搜索起点 |
| 候选 | 旧MILP一次解 | 双起点各保留初值/最低评估/返回点；午夜六候选，日内追加keep_current为第七候选 |
| 结算 | 旧A一次最终量规则 | 相同A真实结算；新日内经验目标也改为剩余段相对午夜q0的F_A，不重复按pq或累加版本账单 |
| PV校正 | 连续版4月启用28日同阶段正PV偏差 | 保留部署日和校正公式，新增历史场景中的校正预测也按各历史日自己的截止重建 |
| 变价 | 因果28日OLS，实际段价格结算 | 正常/紧急规划项统一代入当前预测价，固定价控制另留；μ=.38232保持不变 |

共同公式：v=q+G−L。v>=0时 c=min(v,5000/6,(10800−E)/.9), d=u=0；v<0时 d=min(−v,5000/6,.9(E−1200)), u=−v−d,c=0。E_next=E+.9c−d/.9。富余w=max(v−c,0)，按PV先用记unused_grid=min(q,w)，其他为弃光；这是已付购电的账务分摊，没有退款或售电收入。

在k时刻剩余段H_k，历史日期集合D_k是前112日历日内已经完整结束并已有B0发布的日期。r_d,k=(L_d−G_d)−(Lhat_d,00−Ghat_d,k)。场景净负荷为Lhat_today,00−Ghat_today,k+r_d,k。对每个场景从当前真实E共享同一q，运行至24点。SOC-only的k源阶段仍为00；新PV对照才使用k发布。校正历史跨越4月时分别保留原PV/当时校正PV残差，不事后同化历史。

J_k(q)=sum(C_k(q))+κ/5*mean(5*p_hat*u)−μ*mean(E_end−E_now)。午夜C=p_hat*q，日内C=p_hat*q0+1.5*p_hat*(q−q0)+−.5*p_hat*(q0−q)+。μ不等于真实收入，也未证明为Bellman值函数。所有已执行段均沉没并固定。

L-BFGS-B仅为不光滑目标的局部候选生成器。在q=q0的合同折点使用中间次梯度p；有限差分不要求折点唯一梯度。non-success按原样记录，有限非负保留候选照常严格重评，并不自动失去物理可行性。多起点/候选保留不能证明全局最优。

新旧费用差同时包含目标、采购可选集合、场景及终态等组合变化。Q3同家族无更新→SOC→原PV才是本轮匹配的信息机制对照，连续SOC路径不同是政策作用的一部分，不强行每日重置。Q4四策略只支持价格×校正的匹配比较，未新增Q4无更新/SOC对照，故不单独量化Q4新PV信息价值。不同价格或交易权限的绝对费用差不能当作单因素贡献。

采用结论基于同一年反复探索的未舍入历史账单；保留负收益日/月、非success、超100万元及不支持替换的结果。通用模型、未来收益、正式题意与全局最优性均未由本实验证明。
