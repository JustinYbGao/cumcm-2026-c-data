# 数据处理说明与未决口径

事实依据为中文原题PDF附录2与中文附件1—5。交接说明和统一方案仅作为内部接口建议。本轮保留111原样，在独立工作区实施。代码、探查、验证、绘图、审计副本及中间文件均在本项目中，不写系统临时目录。

## 时间与功率：当前采用但待确认

1. 原表00:10映射到00:00–00:10，0:00+1映射到当日23:50–次日00:00。原标签另列保留。原题说明+1含义，但未完全明确标签是区间起点还是终点；附件5又出现整体晚十分钟的区间标签。因此该映射是显式假设，不能称为官方结论。
2. 附件1/2负载和PV按十分钟区间平均功率解释，电量=功率/6。原始kW字段保留，派生电量为kWh；没有提前四舍五入、标准化或削峰，净负载可以为负。
3. 附件1没有来源日期，q1_day与fixed_price使用1—144时段、start_minute/end_minute及日内时间。末段end_time=24:00:00是日内持续时间表示，不应交给通用日期解析器当真实日期。其可计算键为分钟偏移和slot_id。全年表均使用完整ISO时间及业务日期，禁止人为给Q1附加2025-01-01等伪来源日期。
4. 全年业务日由interval_start所属日确定。2025-12-31最后区间止于2026-01-01T00:00:00，仍属12月31日。所有题目时间无时区，不调用UTC转换；决策接口拒绝带时区时间以防静默偏移。
5. 默认区间结束即完整可用（包含恰好结束的区间）。如果计量有延迟，应由队伍重新定义available_time及接口；本轮未擅自模拟延迟。

上述假设集中登记在configs/data_processing.json。当前实现仅支持登记口径；改变配置中的描述不等于已实现另一种处理算法，变更算法须同步修改代码、重新生成并验证所有下游数据。

## 小时预报转换

先将附件3空字符串日期识别为空，严格按原顺序向下填充，再按原始列h=1…24展开。target_time=issue_time+h小时；唯一键为issue_time+target_time，不按目标时间去重。日期填充1095条逐单元格记录见data/interim/transformation_log.csv，原日期标签也保留。没有对任何功率数值修正、排除或填补。

附件3明确给出整点功率，本轮把它解释为点值，与相邻整点连接为线性曲线。每个十分钟区间[a,b]的预测电量为 `(P(a)+P(b))/2 × 1/6`。这不是把整点预测直接当小时平均再重复六次；不会与实际区间平均功率的换算混淆。

发布时间t到t+1小时缺少当前版本的t端点。采用严格早于t且以t为目标的最新旧版本预测作为端点代理。本数据中就是t−6小时版的h=6值。只在首小时使用这一旧版值，t+1到t+24完全使用当前版本。endpoint_issue_time和endpoint_rule记录该来源，结合小时表可找到源单元格。端点是预测代理，不是当前真实瞬时PV，也不是未来实际PV。

全年第一份2025-01-01T00:00:00没有旧版本，也没有原题提供的0点观测。该版只生成01:00–24:00共138段，首小时6段不生成，coverage表明确记录。其他1459份各144段，总210234行。没有填零、后向读取未来实际值或延长到发布后24小时之外。模型调用第一天应识别这一缺口；题目正式结果覆盖2—12月，每次发布的24小时在本口径下均完整。

跨年预报与派生区间全部保留，包括2026-01-01白天。没有实际值的目标不填零。补充阶段已生成统一小时电量口径的误差表：预测积分电量和实际电量分别按同一小时的完整6段求和，不直接把整点预测与十分钟平均功率相减。35040条原版本—目标记录全部保留，其中35003条可比较，1条缺预测，36条（18个不同小时）缺跨年实际值。MAE/RMSE仅描述已有预报在当前转换假设下的误差，未训练或校准模型。

严格版本比较采用四个版本都完整的8742个相同目标小时，避免不同版本选择不同样本。actual_positive_pv表示事后实际小时电量>0，仅用于诊断分组，不是当时可用的输入特征。误差仅在error_available_time=目标小时末后可进入errors_at历史切片，未完整小时永不填零加入历史误差。

## 原始值与可追溯性

- 原值字段直接来自工作簿数值区域，CSV保留浮点精度。原文件SHA-256清单用于确认输入与模板没有被修改。
- Q1与固定价保留附件1源行号，价格/负载/PV分别对应B/C/D列，原始时间在A列。
- 全年表分别保留负载、PV、电价的源行号、列字母、原时间标签，源文件/工作表固定映射见数据字典。不同来源按完整时间键一对一外连接，任何缺失或扩行立即失败；固定价按slot_id多对一连接。
- 小时表保留源行列、原日期/发布钟点与日期填充标记；派生电量由同版相邻整点和必要的旧版端点复算。
- 只生成日期结构填充记录，没有数值修正。最大的观测跳变仅列举，不判定其为测量错误。
- ~$文件是Excel锁文件，不是官方附件内容，不参与读表及输入哈希。

## 信息隔离和后续确认

实际价格、固定价格分列；未产生任何价格预测列。actual_10min是用于保存与回放的全量归档，不能直接作为决策时未来可见数据。应通过history_at获取决策前已完成区间，再通过forecasts_at获取已发布且目标尚未执行的各预报版本。固定价格从独立表读取，不需要读取未来实际行。

待队伍确认：时间标签与模板映射、实际功率平均值假设、线性积分和旧版首小时端点、测量可用性、未来实时价格是否提前已知。储能效率、SOC跨日衔接、Q2以后终端条件、调整计费等由建模阶段决定；数据脚本没有写入这些策略假设或生成虚构结果。
